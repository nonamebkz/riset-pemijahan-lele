# Bahan asli (`raw/`)

Konvensi penamaan (2026-09-30):

- Huruf kecil, kata dipisah tanda hubung (`kebab-case`).
- Nama menggambarkan **topik/isu**, selaras `source_id` di `state/sources.md` bila memungkin.
- Tanpa spasi dalam nama berkas.

Jika berkas diganti nama, jejak lama dicatat di registri sebagai **Alias lokasi**.

**Jangan** mengubah isi berkas asli tanpa versi baru; agen wiki hanya membaca kecuali pengguna meminta migrasi penamaan.
