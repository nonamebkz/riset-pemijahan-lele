Untuk poin **"DO terukur di kolam pengguna vs target >5 mg/L; penyesuaian blower jika telur terganggu arus"**, jawaban sebaiknya berbentuk **metode kalibrasi lapangan dan tindakan koreksi**, bukan hanya angka target. Berikut formulasi teknisnya:

---

## Kalibrasi DO Kolam Pemijahan Lele & Larva

### 1. Pengukuran DO Aktual Kolam Pengguna

**Parameter target:**

| Fase | Target DO |
|---|---:|
| Telur (0–3 hari) | ≥ 5 mg/L |
| Larva awal (3–14 hari) | 5–7 mg/L |
| Benih >14 hari | 4–6 mg/L |

Pengukuran dilakukan menggunakan **DO meter digital** pada tiga titik:

1. **Dekat kakaban** (zona telur)
2. **Tengah kolam**
3. **Area keluaran/arus aerasi**

Waktu pengukuran:
- Pagi hari (05.00–07.00) → kondisi DO terendah
- Sore/malam (18.00–21.00) → evaluasi kestabilan aerasi

---

## 2. Evaluasi Hasil Pengukuran

### Kondisi A — DO <5 mg/L

**Indikasi:**
- Telur berwarna putih/mati meningkat
- Larva berkumpul di permukaan
- Pergerakan ikan lambat

**Penyesuaian:**

| Tindakan | Pengaturan |
|-|-|
| Tambah kapasitas blower | +20–30% debit udara |
| Tambah titik diffuser | dari 4 menjadi 6 titik |
| Bersihkan batu aerasi | jika gelembung mengecil |
| Kurangi kepadatan telur | jika biomassa terlalu tinggi |

Contoh:
- Awal blower 20 L/menit
- DO hanya 4,2 mg/L

→ naikkan menjadi:

\[
20 \times 1,3 = 26 L/menit
\]

---

# 3. Penyesuaian Jika Arus Mengganggu Telur

Pada fase telur, masalah utama bukan kekurangan oksigen saja, tetapi **kecepatan arus terlalu tinggi yang menyebabkan telur terlepas dari kakaban atau mengalami gesekan**.

### Indikator arus terlalu kuat:

- Kakaban bergerak terus-menerus
- Telur terlepas dari media
- Telur berkumpul pada satu sisi kolam
- Gelembung besar langsung mengenai kakaban

---

## Koreksi Blower

Jangan langsung mematikan aerasi, tetapi lakukan **throttling debit udara**.

### Pengaturan:

| Kondisi | Setting blower |
|-|-:|
| DO <5 mg/L, arus aman | Naikkan 20–30% |
| DO >5 mg/L, telur terganggu | Turunkan 30–50% |
| DO stabil, telur normal | Pertahankan |

Contoh:

Sebelum:
- Blower 40 L/menit
- DO 6 mg/L
- Kakaban bergerak kuat

Penyesuaian:

\[
40 \times 50\%=20 L/menit
\]

Kemudian ukur ulang DO setelah 30–60 menit.

Target akhir:
- DO tetap ≥5 mg/L
- Kakaban hanya bergerak ringan
- Telur tetap menempel

---

# 4. Rekomendasi Layout Aerasi untuk Telur

Agar DO tinggi tetapi telur tidak terganggu:

```
+-----------------------+
| Kakaban       Kakaban |
|                       |
|  ○             ○      |
|                       |
|  ○             ○      |
|                       |
+-----------------------+

○ = diffuser aerasi
```

Prinsip:
- Diffuser ditempatkan di sisi kolam
- Hindari gelembung langsung menuju kakaban
- Gunakan batu aerasi halus (fine bubble)
- Gunakan valve tiap jalur agar debit dapat diatur

---

## 5. Standar Operasional Kalibrasi

| Parameter | Target |
|-|-:|
| DO minimum | ≥5 mg/L |
| Frekuensi cek DO | 2×/hari |
| Penyesuaian blower | bertahap 20–30% |
| Kecepatan arus | lembut, kakaban tidak bergeser |
| Operasi aerasi | 24 jam |

---

### Kesimpulan Teknis

Pada kolam pemijahan lele fase telur, **DO >5 mg/L harus dicapai tanpa menciptakan turbulensi tinggi**. Jika DO rendah, kapasitas blower atau jumlah diffuser ditingkatkan. Namun apabila telur terganggu oleh arus, debit udara dikurangi melalui valve (bukan mematikan aerasi), sambil mempertahankan DO minimal 5 mg/L. Kalibrasi akhir dilakukan berdasarkan kombinasi **nilai DO terukur + respons fisik telur pada kakaban**.
